# Stream Wars: Amazon Prime vs Netflix — Power BI Dashboard

## Project Overview
A comparative analysis dashboard built in Microsoft Power BI,
visualizing content data from Amazon Prime Video and Netflix.

(![Dashboard Preview](streamwars%20pic.png))

## Key Insights
- Amazon Prime has more total titles — 9,687 vs Netflix 8,809
- Netflix has higher TV Show share — 30.38% vs Amazon Prime 19.16%
- Amazon Prime has more Directors — 5,771 vs Netflix 4,527
- Average Movie Duration across both platforms — 94.95 minutes
- TV-MA is the most common content rating at 29.52%
- Drama is the dominant genre on both platforms
- Content growth on both platforms exploded after year 2000

## Tools Used
- Microsoft Power BI Desktop
- Power Query
- DAX (Data Analysis Expressions)
- Bing Maps
- Custom Dashboard Design
